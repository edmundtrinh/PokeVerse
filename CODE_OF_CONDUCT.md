# Code of Conduct

PokéVerse follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text at that link is this project's code of conduct.

## In short

- **Be welcoming.** Players and collectors of every age, background, and experience level are part of this community, including people who are brand new to coding.
- **Be kind and constructive.** Critique ideas and code, never people. Assume good intent.
- **No harassment or discrimination** of any kind, including in issues, pull requests, discussions, and anywhere else you represent the project.
- **Respect privacy.** Don't share anyone's personal information without their permission.
- **Keep it safe for younger fans.** Pokémon has a young audience, so keep language and content appropriate.

## Scope

This applies in all project spaces (the repository, issues, pull requests, and discussions) and when you represent the project elsewhere.

## Reporting

- **Contact the maintainer privately:** reach [@edmundtrinh](https://github.com/edmundtrinh) through GitHub, or use the repository's private security advisory form if you need a confidential channel.
- **Confidentiality:** reports are handled confidentially.

## Enforcement

The maintainer enforces this code of conduct following the Contributor Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines). Responses range from a correction to a temporary or permanent ban.
